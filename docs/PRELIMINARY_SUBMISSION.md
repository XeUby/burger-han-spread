Project name: Burger Han — Spread Dispatcher

Challenge: Spread by Bahn Express

Short description:
An autonomous dispatcher for a simulated car transport company in Finland. It selects feasible orders, quotes dealers and prices freelance driver gigs to maximize gross margin while keeping at least 90% of won orders on time.

Current implementation:
Python dispatcher using Bahn's official API client. A working practice runner records events and scores; pricing and driver-fee policies are separate modules so teammates can develop and evaluate them independently. Initial level-8 experiments show positive margins and meet the delivery threshold. Broader validation and live-final reliability testing are ongoing.

Planned improvements:
Driver availability-aware admission, adaptive prices, multilingual note constraints and better use of driver routes. Each improvement will be evaluated against the previous version on the same practice weeks.
